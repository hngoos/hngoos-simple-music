# Source provenance

Hngoos Simple Music (HSM) is a modified distribution maintained by hngoos.

- Original app: [maxrave-dev/SimpMusic](https://github.com/maxrave-dev/SimpMusic)
- App commit: `fbdba0daa447c93f43a81201a1063d42941665d5` (dev branch)
- Original core: [maxrave-dev/core](https://github.com/maxrave-dev/core)
- Core commit: `164e89e0d093492d6f1c9be3f745201b7b4574bb`
- Imported sources and HSM modifications: November 13, 2026.

Core is vendored, rather than a Git submodule, so this repository contains the
source needed to build the modified app. Upstream copyright and GPL notices
remain in place; see LICENSE and core/LICENSE. The upstream commit history is
retained in Git. HSM branding derives from the owner's HDM mark.

HSM changes include its name and icons, independent desktop data and distribution
identity, Apple Music inspired desktop listening UI and playlist import flow.
Spotify, Apple Music, YouTube, SimpMusic Lyrics and other service names identify
their respective services; HSM is independently maintained.
